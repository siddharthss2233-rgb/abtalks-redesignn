# ABTalks Redesign

## Overview
A modern redesign of the ABTalks platform built using React, Vite, and Tailwind CSS.

## Features
- Modern Landing Page
- Personalized Dashboard
- Smart Search
- AI Recommendations
- Talk Details Page
- Profile Page
- Responsive Design
- Dark Mode

## Tech Stack
- React
- Vite
- Tailwind CSS
- Bolt.new
- Vercel
